# Readyville Wrestling Universe

A custom action-figure wrestling tournament simulator built for mobile/tablet use.

## GitHub Pages

After uploading these files to the root of the `main` branch:

1. Open **Settings** in the repository.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

The site will be available at:

https://caleb-mckinney.github.io/readyville-wrestling-universe/

On Android, open the site in Chrome and use **Add to Home screen** / **Install app**.
